# Sportsman - Sports Management Website

A simple and responsive website for managing athletes, coaches, schedules, attendance, and performance. 
Built using only **HTML, CSS, and JavaScript** - no frameworks.

Live Demo: https://sportsmanagment-326-uu1y.vercel.app

---

## 🚀 Features

- **Home Page** - Sports We Offer cards with a sporty design
- **Athletes Page** - Add, view, and filter athletes
- **Coaches Page** - View coach cards and details
- **Schedule Page** - Training schedule and filter bar
- **Attendance Page** - Mark and track attendance
- **Performance Page** - Track athlete performance
- **Responsive Design** - Works on laptop and mobile

---

## 🛠️ Technologies Used

- **HTML** - Structure of the website
- **CSS** - Colors, layout, and design
- **JavaScript** - Forms, filters, and interactivity
